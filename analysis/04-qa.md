## 4.1 알려진 버그 이력 (커밋 메시지 추출)

| 버전 | 유형 | 증상 |
|---|---|---|
| v1.2.2 | fix | 스테이지 클리어 **연쇄(chain)** 발동 |
| v1.2.1 | fix | 웨이브 진행 반영 실패 |
| v1.1.x | fix | 웨이브 카운트 이상 |
| v1.0.1 | refactor | 시너지 과다 적용 (속성 재설계) |
| v0.9.4 | remove | HP 업그레이드 **과다 강력** → 시스템 자체 제거 |
| v0.9.2 | perf | 적 군집 겹침 (Object Pool + 분리) |

**패턴 분석:** 버그 대부분이 **상태 전이(state transition) + 밸런싱(balancing)** 두 축에 집중.
- 상태 전이: 스테이지·웨이브·조립 모드 간 전환에서 플래그 누락
- 밸런싱: 수치가 즉흥적 조정 → 재조정 반복 → 가끔 시스템 제거

**회귀 방지 전략:** 각 상태 전이를 FSM으로 명시화 + 스모크 테스트 필요.
